## Derivation
For full two-port groups, validated upper K_ij=u_i v_j^T, lower K_ij=x_i y_j^T, i != j, with 2x2 diagonal blocks. Anchors selected from end-to-end cross block, largest magnitude. All cross-block elements must match to 64 double eps relative, or reject. A=I-DK has generators U=-D u, X=-D x and original v,y; diagonal B=I-D K_ii. In block elimination the trailing Schur update has form X_i S v_j^T and RHS update X_i T. At block i, invert B_i-X_i S v_i^T, obtain w_i for corrected RHS and z_i for U_i-X_i S, update S+=(y_i-S v_i)^T z_i and T+=(y_i-S v_i)^T w_i. Backsolve q_i=w_i-z_i times the suffix sum of v_j^T q_j. Strictly, q_i=w_i-z_i*(suffix). dp=r+Kq using original full K; require q approximately equals D dp. Ill-conditioned determinants and guard failures fall back to the unchanged pivoted solver. The full reconstruction is O(M^2); structured elimination itself O(M). No removed physical couplings. This is a numerical prototype, not a proof of conditioning for all operating points. In particular no pivoting between blocks, guard thresholds still require validation against physical extremes and fault injection.

## Decision
Promising numerical fidelity in limited synthetic comparison, modest mean gain in one ABBA set, no robust deadline proof. Keep prototype separate, DO NOT merge to Source/dsp or claim product CPU gain. Next improve structured algorithm using conditioning/scale-aware checks, actual Newton-system captures and negative tests; verify fallback for singular, invalid and extreme cases, full original fault suite and noise-on parity, repeat paired benchmark with full JUCE/Windows build. Investigate larger leverage in power amp and DK reactive state products, not repeated failed SIMD row tweaks. Native Windows / owner CPU / full VST3 / DI / GUI / DAW NOT RUN. No CI triggered.
