## Numerical power functions
The Koren triode eval repeatedly computes (vpk/kp)^(1.4-1); power screen terms and screen current compute x^1.35. Current code uses exp(a*log(x)); preserve model and exact reference eval paths. Test-only header FastPowerPrototype.h uses positive binary64 decomposition x=2^e*m; m in [1,2), e=-100..100. Precomputed 256 midpoint powers/inverses and 201 exponent powers, relative local t=(m-mid)/mid, |t|<1/512. Degree-5 binomial expansion of (1+t)^a; truncation at order six, estimated from formula, not a universal machine-error proof. Outside exponent range retain original expression, including zero/subnormal/negative/nonfinite. No global fast-math, no solver tolerance or sample-rate change. Prototype assumes IEEE binary64; function-local static initialization must be moved/forced into off-RT prepare before any product use. First draft table covered 2046 exponent values, which could overflow for a=1.35; narrowed actual tested table to 201 entries before final tests.
